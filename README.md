# 📈 A股大事件日历（单文件日历页 + 事件雷达）

把每天几百条财经电报，压缩成一页"**能看的**"**中国股市大事件日历**——覆盖 A 股（沪深北），兼顾港股与外资视野，开源免费。

- **单 HTML 文件**，双击即用，无账号、无后台依赖（可独立运行）
- 事件雷达（本地 Python 服务）持续抓取电报流，按 **关键词粗滤 → 高确定性噪音规则族 → LLM 语义判读** 三级管道，把 4 万+ 条原始电报压成 140+ 条"值得上日历"的事件；**前两级粗滤已在电报入库瞬间由服务端就地执行**——所以新用户从第一天起，判读队列里只有硬候选
- 一切停在 127.0.0.1，数据全本地（`radar.db` / `data.json` 均不入库）

![日历全景](https://testingcf.jsdelivr.net/gh/king151/a-share-event-calendar@master/docs/screenshots/calendar.png)

## 核心特性

### 日历（主视图）
- **7 列月网格**、格内横排事件条：一天一行能站 5~7 条，密集日不裁剪
- **状态守色相，星级管深浅**：发=橙红 / 落=蓝 / 关注=紫 / 自查=青；★★★★ 深底白字、★★★ 加粗、★ 极浅——一眼分轻重
- **方块就是量杯**：格子底部水位条 = 当日最大金额（对数刻度），月度资金密度可视化
- 每格右上角 **日消化率%**：当日电报里被判读/丢弃/高确定性粗滤直击的比例，雷达"漏斗"是否健康一眼可见
- 倒计时徽章（剩 N 天）、多源合并徽章（源+N）、候选事件虚线米黄突出、悬停迷你卡、点击详情弹层（金额量杯、时间线、官方原文链接）

### 外壳一行化
标题 / 近期提醒胶囊 / 六个操作按钮一行，市场·类别·等级·标签·状态·搜索一行，图例+统计+判读进度一行——共 **144px**，`fitRows()` 把省出的空间全部还给日历格（行高 127~157px，整月溢出 0px）。142 个标签 chips 折进「标签 ▾」开关，激活时自动展开并亮 ●N。

### 时间线视图
按发生/落地排序（可正可倒）的事件列表，AI 判读标签、金额、板块一应俱全。

![时间线视图](https://testingcf.jsdelivr.net/gh/king151/a-share-event-calendar@master/docs/screenshots/timeline.png)

### 事件详情
金额量杯（<10亿 → >1000亿 对数刻度）、状态/等级/板块、信息源头原文链接、事件时间线、关注日（独立截止节点）。

![事件详情](https://testingcf.jsdelivr.net/gh/king151/a-share-event-calendar@master/docs/screenshots/detail.png)

### 事件雷达（📡 后端）
```
电报流(直播+历史存档) ──入库即预筛──▶ P4/DIGEST/hi噪音族 ──▶ filtered（hi=可信排泄，计入消化率）
                  │
                  └─硬候选(IPO/大额/政策/行业) ──▶ pending ──▶ LLM 语义判读（annotate.py，人工闭环批处理）
                                       建/并 ──▶ events 表 ──▶ data.json ──▶ 日历页
```
- 预筛规则同一套代码跑两处：服务端入库当场分流（`radar_server.py` 调 `radar_prescreen.py`），存量库历史清洗用离线脚本（`prescreen_fclass_backfill.py`）
- **消化率 = (判 + 丢 + 高确定性粗滤直击) / 当日电报总数**，当前 **60.5%**（从 38% 挖上来：`mid_families_mine2.py` 文段挖掘 → `fam_eval2.py` 量化 → 12 个零误杀规则族 → 回补 +9290 条）
- 市场三视野：**A股 / 港股 / 外资**（`events_market_classify.py` 四层优先级分类 + 31 条内建测试）
- 判读纪律：**宁缺毋滥**——金额必须可查证、落地日必须有官方原文，查不到就留空，不编造

## 快速开始

```bash
# 1. 启动事件雷达（端口 7610；需 Python 3.10+）
pip install akshare
事件雷达/启动雷达.bat          # 或：pythonw radar_server.py

# 2. 双击 大事件日历.html —— 完事
# 页面会自动连 127.0.0.1:7610 拉取快照；雷达不在也能以前端缓存独立打开
```

- `启动雷达.bat` 会自动找 Python（环境变量 `RADAR_PYTHON` 可指定全路径 → PATH 里的 `pythonw` → `python`），启动后自检 `/api/ping`
- **排错**：一切异常都留痕在 `事件雷达/radar.log`；启动失败多半是没装 akshare（报 `No module named akshare`）或 Python 不在 PATH

> 🎬 **想立刻看到完整效果？** 新库起点是空的（判读遵循「宁缺毋滥」，需要逐批裁决事件才会入库）——顶栏 **导入数据 → 选择 `docs/demo.json`**，即可载入 185 条示例事件马上体验日历全部形态；体验完用顶栏「重置」清空，再走真实数据流。
>
> 📜 **想带近三个月历史电报**（可选，一次性）：`python 事件雷达/cls_backfill.py` —— 慢速分页抓取约 30 分钟（对源站友好，断点续传），落成 `cls_backfill.jsonl`；之后每次 scan 会自动入库去重。不跑也不影响使用，只是起点只有当天直播电报。
>
> 正常 `scan` 只做增量抓取（直播电报 + 已回填存档），硬候选自动打包成 `judge_queue/batch_auto_*.jsonl`，供逐条裁决（可人工，也可接 LLM，见 Roadmap）。

> 🔍 **冷启动第一天你会看到**：日历基本是空的、待判硬候选只有个位数——这是台账纪律不是故障。历史事件随日常 scan 与判读逐批入库，也可以先跑上面的历史回填。

导入/导出/添加事件都在顶栏按钮，`data.json` 即是权威数据源，可直接放进你的同步盘带走。
