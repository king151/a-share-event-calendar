📈 A股大事件日历（单文件日历页 + 事件雷达）

把每天几百条财经电报，压缩成一页"能看的"中国股市大事件日历。开源免费（MIT），双击即用，全部数据停留本地。

⭐ GitHub 仓库 🚀 三步跑起来
三级压缩管道
财联社电报流 → 入库即预筛（关键词+高确定性噪音规则族）→ 硬候选 LLM 语义判读 → 4 万+ 条电报压成 140+ 条"值得上日历"的事件
消化率漏斗
每格右上角显示当日"判+丢+粗滤直击"比例，雷达是否健康一眼可见；当前 60.5%
台账纪律：宁缺毋滥
金额必须可查证、落地日必须有官方原文，查不到就留空，不编造
法定假日/休市层
2026 放假调休直接标在格上：🏮 放假日（休市）与「调」调休上班日，数据逐字对齐国办文件与沪深交易所公告
单文件 + 全本地
无账号无后台依赖，数据全在 127.0.0.1；data.json 即权威数据源，可直接放进同步盘

三步跑起来

  • pip install akshare
  • 启动 事件雷达/启动雷达.bat（自动找 Python，端口 7610，自检 /api/ping）
  • 双击 大事件日历.html —— 完事。想先看效果：顶栏 导入数据 → docs/demo.json
